# isochron-fingerprint

Code and data for **"A Geometric Framework for Characterizing Classical Neuronal
Models Using Isochron Foliations"** (T. D. Paes, J. M. X. de Lima, A. Pereira Jr.,
CBEB 2026 — IEEE Proceedings).

The framework computes the isochron foliation of a planar limit-cycle oscillator
and summarizes it by six descriptors (a *geometric fingerprint*):
mean phase-gradient magnitude, its CV and Gini coefficient, the coherence radius,
the Floquet contraction per cycle, and two PRC shape indices.
Every number, table and figure of the paper is regenerated by the scripts below.

## Install
```bash
pip install -r requirements.txt
```
Tested with Python 3.13, NumPy 2.5.3, SciPy 1.18.1, scikit-learn 1.9.1, Matplotlib 3.11.2.

## Quick start
```python
from isofp import core, models
p = dict(models.FHN_BASE, I=0.972)
d = core.run(models.fhn, p, x0=[0.0, 0.0], t_trans=1200)
print({k: v for k, v in d.items() if not k.startswith('_')})
```

## Package `isofp/`
| file | content |
|---|---|
| `models.py` | FitzHugh–Nagumo, Morris–Lecar (Type I / Type II sets), Hindmarsh–Rose fast subsystem, Stuart–Landau (+ closed-form phase) |
| `core.py` | limit cycle → non-dimensionalization → grid → vectorized RK4 → asymptotic phase → wrap-aware gradient → adjoint iPRC → descriptors |
| `sweep.py` | the 63 parameter points (paper Table VIII) |
| `reps.py` | one representative point per family |
| `stats.py` | η², AUC, extrapolation-split classification with permutation test |

## Reproducing the paper
`./run_all.sh` runs everything (≈2–3 h on two cores). Individually:

| script | paper |
|---|---|
| `run_validation.py` | Sec. IV, Table II (Stuart–Landau ground truth) |
| `run_sweep.py` | Tables IV–VI, Fig. 3 |
| `run_sweep_variant.py TAG key=value` | Table III (`Euler method=euler`, `N48 N=48`, `N112 N=112`, `W12 half_width=1.2`) |
| `run_sensitivity.py` | Sec. V, Fig. 2 |
| `run_invariance.py` | Sec. III-C, Table I |
| `run_physio.py` | Sec. VII, Table VII, Fig. 4 (in-silico current-pulse protocol) |
| `make_*.py` | figures (`figures/`) and table values (`out/tables.json`) |

`out/` contains the results used in the paper, so tables and figures can be
regenerated without re-running the simulations. Seeds: 0 (permutations),
1 (grid offsets).

## Notes
* The phase on the limit cycle is uniform in **time** (asymptotic phase).
  `core.run(..., labelling=('time', 'arc'))` also returns the arc-length
  labelling of the preliminary version, used only to show that it breaks
  unit invariance.
* The Izhikevich model (discontinuous reset) is outside the scope of the
  current implementation.
